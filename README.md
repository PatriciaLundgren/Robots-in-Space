## 🎮 Play Now

**👉 [Play Robots in Space on Unity Play!](https://play.unity.com/en/games/ea8cb77e-c3f3-49eb-9e62-63a50fe75148/robots-in-space) 👈**

## 🕹️ Controls

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | `W` `A` `S` `D` or Arrow Keys | Left Stick |
| Look around | Mouse | Right Stick |
| Jump | `Space` | South Button (A / Cross) |
| Sprint | Hold `Shift` | Left Trigger |

Just walk into items to pick them up — no button required. And don't worry about falling off the level, your robot respawns automatically. 🌟
